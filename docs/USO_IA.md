# Registro de uso de IA

A IA foi usada como ferramenta de apoio, não como substituta de validação técnica. O trabalho foi dividido em leitura
dos requisitos, proposta de arquitetura, implementação inicial, revisão e documentação.

## Prompts representativos

- "Extraia requisitos funcionais, não funcionais, restrições e critérios de entrega do enunciado."
- "Proponha arquitetura em camadas para Java 21/Spring Boot e React/TypeScript."
- "Gere implementação demonstrativa de opt-in, agenda, portabilidade idempotente, HMAC, confirmação assíncrona e
  auditoria."
- "Liste riscos, trade-offs e testes necessários para validar a solução."

## Restrições

- Não inserir credenciais reais ou dados pessoais reais.
- Revisar código gerado e executar testes/build antes da entrega.
- Identificar explicitamente limitações e decisões que exigem evolução para produção.
